# Security

The app talks to exactly one thing: the XaeroDeck mod's HTTP server on your
own LAN. No analytics, no accounts, no third-party SDKs, no cloud relay.
Release APKs are built by GitHub Actions from the tagged source.

Full threat model and "is this a RAT?" FAQ:
